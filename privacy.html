Privacy Policy

Service: Crawl Data — personal/internal data tool. Last updated: October 30, 2026.

1. What We Collect

This tool is a local, single-user command-line application. It does not collect personal information through a website, app store, or any third-party service. When you authorize a TikTok account, the TikTok API returns only the profile and statistics data for that specific account (username, follower counts, video statistics) in order to complete the authorized request.

2. How Data Is Stored

All retrieved data is stored exclusively on the local machine of the user, in a SQLite database file (data/tiktok.db) and exported spreadsheet files (exports/). No data is sent to any external server, analytics service, or third party.

3. Tokens

OAuth access and refresh tokens returned by TikTok are stored locally in the same SQLite database, encrypted at rest only to the extent of your operating system's file permissions. These tokens are used solely to re-authenticate and refresh data for the accounts the user has explicitly authorized.

4. No Sharing, No Sale

We do not sell, rent, or share user data with anyone. There are no cookies, trackers, or analytics on the associated pages.

5. Your Choices

You may revoke access at any time through TikTok's account settings (Security & Privacy → Connected apps), which will invalidate the tokens stored locally. Deleting the local database files removes all stored data.

6. Contact

Questions about this policy: contact the owner of the application (registered in the TikTok Developer Console).

Tóm tắt bằng tiếng Việt

Đây là ứng dụng command-line chạy cục bộ, không thu thập dữ liệu qua website hay dịch vụ bên thứ ba. Khi ủy quyền tài khoản TikTok, API chỉ trả về thông tin hồ sơ và thống kê của đúng tài khoản đó. Toàn bộ dữ liệu và token OAuth được lưu cục bộ trên máy người dùng (file SQLite và file xuất), không gửi đi bất kỳ máy chủ nào. Người dùng có thể thu hồi quyền truy cập bất kỳ lúc nào qua Cài đặt bảo mật TikTok; xóa file cơ sở dữ liệu là xoá toàn bộ dữ liệu đã lưu.
